# 年末年始ご挨拶ページ 設計方針

## 目的とトーン
- 年末年始のご挨拶と休業案内を、落ち着いた信頼感のあるトーンで届ける。
- コーポレートカラーのネイビー（#082E5D）を軸に、淡いブルーと余白で清潔感と安心感を演出する。

## 情報構造
1. **メタ情報とタイトル**
   - `.greeting-meta` でカテゴリバッジと公開日を並列表示し、記事の性質と鮮度を明示する。
   - 見出しは `.greeting-card h1` で26px・太字に統一し、タイトルと本文のヒエラルキーを明確にする。
2. **リードと本文**
   - `.lead` で挨拶の要旨を短くまとめ、続く本文で感謝と状況共有を行う。
   - 行間（line-height: 1.8）を確保し、長文でも可読性を維持する。
3. **重要情報の強調**
   - `.highlight-box` を使って休業期間のコアメッセージを帯域で強調する。
   - `.info-grid` と `.info-item` で休業期間・対応再開日・お問い合わせ案内をカード表示し、パッと見で比較できるようにする。
4. **お問い合わせ導線**
   - `.contact-cta` を本文末に配置し、目立つ枠線ボタンでフォームへ誘導する。

## スタイリングの要点
- 角丸6pxとシャドウ（0 2px 6px rgba(0,0,0,0.1)）でカード感を出し、ページ全体の立体感を統一。
- `.info-item .label` は大文字と文字間隔でタグ的に見せ、`.value` は17px・太字で主要情報を強調。
- ホバー時はボタンの背景をネイビーに反転させ、アクセシビリティを損なわない範囲でコントラストを強調。

## 更新時のチェックリスト
- 休業期間・対応再開日が `.info-grid` 内で日付形式・表記ゆれなく整理されているか。
- 土曜稼働など実態と異なる注記が残っていないか（不要な場合は削除済みか確認）。
- CTAのリンク先（フォームURL）が最新か、外部リンク切れがないか。
- OGタグ（タイトル・説明・URL・画像）の内容が最新のページ内容と整合しているか。
