# テキストHTML変換ツール 仕様書

## 目的
Excelで作成した文章をコピーして貼り付け、簡易的なHTML（`p, br, b, a`）に変換する作業を効率化する。
テキスト装飾（改行・太字・文字色・URL）を可能な限り引き継ぐ。

## 画面構成
1. 入力（原稿）
2. プレビュー（見た目）
3. HTMLソース（コード）

## 主要機能
1. **改行の保持**
   - 入力内容の改行はHTML上の段落・改行として維持する。
2. **太字の保持**
   - b 相当の太字を保持する。
3. **文字色の保持**
   - 黒以外の文字色を保持する。
4. **URLの自動リンク化**
   - テキスト中のURLを自動で `<a>` タグに変換する。
5. **クリップボードコピー**
   - 変換結果をコピーできる。

## 変換仕様（入力→出力）
### 1. 入力ソース
- Excelで作成した文章をコピーし、`1. 入力` エリアへ貼り付ける。
- 入力内容はHTMLとして解析し、`p, br, b, a` のみを残す。

### 2. 保持する要素（タグ）
- `p, br, b, a`

### 3. 保持する属性
- `href, target, rel, style`
- `style` は `color` と `font-weight` のみ保持する。

### 4. 文字色の扱い
- 黒以外の色指定は保持する。
- `style="color: ..."` および `color="..."` を対象とする。

### 5. 太字の扱い
- `b` は保持する。
- 太字スタイルは必要に応じて `b` に寄せて維持する。

### 6. 改行の扱い
- 空行は `<br>` に変換して保持する。

### 7. URLの扱い
- 既存の `<a>` は維持する。
- テキスト中のURLは自動でリンク化する。

### 8. 除去される装飾
- フォントサイズ、背景色、余白などの装飾は除去する。

## 入出力例
### 入力
```
タイトル
赤字の文言
https://example.com
```

### 出力
```
<p>タイトル</p>
<p><b style="color: red; font-weight: normal;">赤字の文言</b></p>
<a href="https://example.com" target="_blank" rel="noopener noreferrer">https://example.com</a>
```
