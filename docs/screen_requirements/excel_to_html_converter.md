# 画面要件定義書：ExcelテキストHTML変換ツール

## 1. 概要
ExcelやWordからコピーした装飾付きテキストを、ウェブサイト更新に適したクリーンなHTMLタグに変換するツール。

## 2. 画面構成
### 2.1. 入力セクション
- **リッチテキスト入力エリア**: 
  - `contenteditable="true"` を持つ `div` 要素。
  - ユーザーがExcel等からコピーした内容を直接ペーストする。
  - ペースト時に自動的にスタイルを解析する。

### 2.2. オプション設定セクション
- **段落処理選択**:
  - `各行を<p>で囲む`: 空行以外の各行を `<p>...</p>` でラップする。
  - `改行を<br>に変換`: 全体を一つの段落とし、改行位置に `<br>` を挿入する。
- **空行の扱い**:
  - `連続する空行を無視`: 複数の改行を一つにまとめる。
  - `空行を<p>&nbsp;</p>にする`: スペースを確保するための空段落を生成する。

### 2.3. 出力セクション
- **HTMLソース表示エリア**:
  - `textarea` (readonly)。
  - 変換後のHTMLコードを表示する。
- **コピーボタン**:
  - クリック時にソース表示エリアの内容をクリップボードにコピーする。

### 2.4. プレビューセクション
- **プレビューエリア**:
  - 生成されたHTMLを実際にレンダリングして表示する。

## 3. 変換ルール
- **太字**: `font-weight: bold` または `<b>`, `<strong>` などを `<strong>` に変換。
- **文字色**: インラインスタイルの `color` を抽出し、`<span style="color: #xxxxxx">` に変換。
- **クリーニング**:
  - `style` 属性のうち `color` 以外のすべてを除去。
  - `class`, `id`, `onclick` などのイベント属性をすべて除去。
  - `font`, `o:p`, `span` (装飾なし) などの不要なタグを平滑化（中身のテキストだけ残す）。
  - `&nbsp;` を通常のスペースに置換（オプションによる）。

## 4. デザインガイドライン
- プロジェクト標準の `bootstrap.min.css` を使用。
- `style3.css` のスタイルと調和させる（フォント、配色など）。
- レスポンシブ対応（PCでの利用を主とするが、崩れないこと）。
