## 事例の共通原稿票

業種・背景 → 作業内容と数量 → 工程 → 納期 → 品質確認 → 結果、の順序を使う。

- 案件名（内部のみ）／公開タイトル:
- 業種・背景／依頼された課題:
- 作業対象・数量・単位:
- 実施工程／納品形式:
- 実納期と算定の起点・終点:
- 品質確認の方法・結果・測定根拠:
- 成果（数値の根拠・比較条件）:
- 顧客名・ロゴ・成果数値の利用許諾、または匿名化範囲:
- 根拠資料の保管場所（秘密情報はこの公開リポジトリに転記しない）:
- 内容責任者／確認日／公開承認:

許諾のない顧客名や架空の成果は掲載しない。情報がそろった事例だけを別PRで追加する。
