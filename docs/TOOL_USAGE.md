# リンステ専用 コンテンツ制作支援ツールの使い方

## 概要
`TOOL/index.html` は、リンステ案件のWebコンテンツ更新作業を効率化するためのポータルページです。
ここから各種ツール（現在は「テキストHTML変換ツール」）へアクセスできます。
主な用途は、Excelで作成した文章をコピーして貼り付け、簡易的なHTML（`p, br, b, a`）に変換することです。
テキストの装飾（改行、太字、文字色、URL）を可能な限り引き継ぐ前提で利用します。

## ツール構成
- **ポータル（クッションページ）**: `TOOL/index.html`
- **テキストHTML変換ツール**: `TOOL/convert.html`

## 主な機能（テキストHTML変換ツール）
1. **改行の保持**
   - 入力内容の改行は、HTML上の段落・改行として維持されます。
2. **太字の保持**
   - 太字（b 相当）は残し、不要な装飾は除去します。
3. **文字色の保持**
   - 黒以外の文字色は保持し、他の装飾は除去します。
4. **URLの自動リンク化**
   - テキスト中のURLを `<a>` タグに変換します。

## 変換仕様（入力→出力）
1. **入力ソース**
   - Excelで作成した文章をコピーし、`1. 入力` エリアへ貼り付けます。
   - 入力内容はHTMLとして解析され、`p, br, b, a` のみを残します。
2. **保持する要素（タグ）**
   - `p, br, b, a`
3. **保持する属性**
   - `href, target, rel, style`
   - `style` は `color` と `font-weight` のみ保持します。
4. **文字色の扱い**
   - 黒以外の色指定は保持します。
   - `style="color: ..."` および `color="..."` を対象にします。
5. **太字の扱い**
   - `b` は保持します。
6. **改行の扱い**
   - 空行は `<br>` に変換して保持します。
7. **URLの扱い**
   - 既存の `<a>` は維持し、テキスト中のURLは自動でリンク化します。
8. **除去される装飾**
   - フォントサイズ、背景色、余白などの装飾は除去されます。

## 使用手順
1. `TOOL/index.html` をブラウザで開きます。
2. Excelから内容をコピーし、「1. 入力」エリアに貼り付けます。
3. 必要に応じて「2. 変換オプション」を調整します。
4. 生成された「3. 出力」のソースをコピーして、各ページの該当箇所に貼り付けてください。

## 注意事項
- 太字・文字色・URL・改行以外の複雑な装飾（フォントサイズ、マージン、背景色など）は、サイトの共通デザインを保つために自動的に削除されます。
- 特殊なレイアウトが必要な場合は、生成後のコードを手動で調整してください。
