# お客様向け自動返信テンプレート編集

問い合わせ台帳にバインドするApps Scriptです。台帳の既存編集者が、メール送信権限を持たずにお客様向け自動返信の下書き、プレビュー、公開、直前版へのロールバックを行えます。

## 初期設定

1. 問い合わせ台帳を、Apps Scriptを所有するWorkspaceアカウントで開きます。
2. `拡張機能` → `Apps Script`からコンテナバインド型プロジェクトを作成します。
3. このディレクトリの`Code.gs`と`appsscript.json`を反映します。
4. 台帳を再読み込みします。必要な設定が未作成の場合は`onOpen`が一度だけ初期設定します。
5. `メール文面管理`メニューが表示されることを確認します。手動で再設定を確認する場合は、Apps Scriptエディタから`setupMailTemplateEditor`を実行できます。

初期設定は既存の問い合わせ行を変更しません。公開フォーム、Worker、通知先、送信ON/OFF、共有鍵にも触れません。スプレッドシートIDや実際のメールアドレスをソース、Issue、ログへ残さないでください。

## 日常運用

1. `メールテンプレート`タブの下書き件名・本文を編集します。
2. `メール文面管理` → `プレビュー`で架空データの表示を確認します。
3. `下書きを公開`を選び、確認ダイアログで公開します。
4. 問題がある場合は`直前の公開版に戻す`を実行します。

下書きの保存だけでは実メールへ反映されません。公開後は受信Apps Scriptの再デプロイなしで、次回の自動返信から新しい文面が使われます。
